# Roadmap: Live City Vitals (OpenWeather & Air Quality)

Building on the "Premium Intelligence" vision, this roadmap outlines how we will integrate live weather and air quality data into `bestcityspots.com`.

## 1. Backend: Data Normalization + Caching
**Goal:** Create a unified server action to fetch and merge weather + pollution data with a safe cache layer.
- **File:** `src/lib/weather.ts` (New)
- **Logic:**
    - Fetch current weather from `/weather`.
    - Fetch current pollution levels from `/air_pollution`.
    - Normalize the AQI (1-5) into human-readable categories (Good, Fair, Moderate, Poor, Very Poor).
    - Cache results in Supabase with a 60-minute TTL to stay under the API quota.
    - Fall back to stale cache on API errors (graceful degradation).
- **Env:** `OPENWEATHERMAP_API_KEY` required in `.env.local`.
- **Impact:** Provides a clean, typed interface for the frontend while protecting API limits.

## 2. Frontend: The "City Vitals" Component
**Goal:** A high-end, live-feel widget for the city detail pages.
- **Component:** `src/components/CityVitals.tsx` (New)
- **Visuals:**
    - Temperature with "Feels Like" (optional min/max if desired later).
    - Air Quality badge (color-coded).
    - Humidity and Wind speed.
- **Impact:** Makes the city page feel "alive" and reactive.

## 3. Page Integration
**Goal:** Inject the widget into the dynamic city routes.
- **Location:** `src/app/cities/[id]/page.tsx`
- **Logic:** Add the `CityVitals` component to the sidebar or header section. Use the server action to fetch data.
- **Fallback UI:** Render a muted "Vitals unavailable" state if weather data is null.

## 4. Comparison Engine Extension
**Goal:** Use live weather as a tie-breaker.
- **Logic:** Update the comparison view to show "Real-time Delta" (e.g., "Right now, London is 15°C colder than Pune").
- **Constraint:** Only show if both cities return valid data (avoid null comparisons).
