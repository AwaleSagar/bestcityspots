# UX Design Checklist - 100 Pro Tips

This checklist is based on [Top 100 UX Design Tips from a User Experience Master (Intechnic)](https://www.intechnic.com/blog/100-ux-design-pro-tips-from-user-experience-master/).

Use this checklist to review and improve the user experience of Best City Spots.

---

## Flow

- [ ] **Tip 1:** Think of the website as a yellow brick road: move users seamlessly from one section to the next by understanding user personas' goals and needs.
- [ ] **Tip 2:** Users are more likely to notice items near the top of the page, in order of their importance.
- [ ] **Tip 3:** Consistent and easy-to-use web interfaces help users concentrate on the content and move through it.
- [ ] **Tip 4:** Avoid creating dead end pages on websites. They cause confusion and create additional work for users.
- [ ] **Tip 5:** Use common website patterns and interfaces; don't make users learn something new.

---

## Scrolling

- [ ] **Tip 6:** Users will scroll down the webpage as long as it is clear that additional, relevant information is below the fold.
- [ ] **Tip 7:** Your website should always provide a strong visual indication of the direction of scrolling and whether more content is available.
- [ ] **Tip 8:** The longer the website page, the less likely someone is to scroll down to the bottom.
- [ ] **Tip 9:** Running webpages are nice because scrolling is faster than clicking — just don't make the pages too long.

---

## Contrast & Color

- [ ] **Tip 10:** Design for color blind users — convert your designs to grayscale to ensure readability.
- [ ] **Tip 11:** Don't use the color blue for text other than links.
- [ ] **Tip 12:** Be aware of contrast on mobile websites — screen glare can render your site unusable.
- [ ] **Tip 13:** Reserve one color for CTAs and don't use it for anything else.
- [ ] **Tip 14:** Warm, bright colors come forward and cold, dark colors stay in the background.

---

## Loading

- [ ] **Tip 15:** Make sure users can complete their primary goal quickly and easily.
- [ ] **Tip 16:** What matters most to users is that your site feels fast (perception counts).
- [ ] **Tip 17:** Perception of speed is based on load time, behavior, waiting, and animation smoothness.
- [ ] **Tip 18:** Show a skeleton of the layout while loading.
- [ ] **Tip 19:** Website text should load before images.
- [ ] **Tip 20:** Delays longer than several seconds often make users leave.

---

## Mobile

- [ ] **Tip 21:** Mobile interface elements that are small/close together are hard to tap.
- [ ] **Tip 22:** Minimum touch target size should be ~1 cm × 1 cm with padding.
- [ ] **Tip 23:** If users need to use a pinky finger, targets are too small.
- [ ] **Tip 24:** On tablets, sides & bottom are most reachable with thumbs.
- [ ] **Tip 25:** Don't require vertical swiping for anything but normal scroll.
- [ ] **Tip 26:** Don't use double taps — favor single-touch interactions.
- [ ] **Tip 27:** Determine one-/two-hand usage when designing mobile layouts.

---

## Navigation

- [ ] **Tip 28:** Always have an obvious way to access the navigation menu.
- [ ] **Tip 29:** If hierarchy is deeper than 3–4 levels, consider a redesign.
- [ ] **Tip 30:** Sticky menus help on long pages.
- [ ] **Tip 31:** Navigation should disappear into the background, not be intrusive.
- [ ] **Tip 32:** Keep navigation consistent across the site.
- [ ] **Tip 33:** Labels should be specific, concise, and information-carrying.
- [ ] **Tip 34:** Use breadcrumbs to show users where they are.
- [ ] **Tip 35:** On mobile, show frequently used options and hide others under a hamburger.
- [ ] **Tip 36:** Hamburger menus on desktops are less noticeable and familiar.
- [ ] **Tip 37:** For secondary navigation on mobile, use landing pages or in-page menus.
- [ ] **Tip 38:** Dropdowns should be vertical, not horizontal hover.
- [ ] **Tip 39:** Megamenus should be narrower than the page so users can "click out."
- [ ] **Tip 40:** Organize megamenu links into groups and distinguish clickable items.
- [ ] **Tip 41:** Don't hide login or search inside menus.

---

## Forms

- [ ] **Tip 42:** Align labels and fields vertically for fast scanning.
- [ ] **Tip 43:** Field labels should be outside the text field.
- [ ] **Tip 44:** Use separators to break up long forms.
- [ ] **Tip 45:** Place form errors next to the specific field.
- [ ] **Tip 46:** Error messages should be helpful, concise, and clear.
- [ ] **Tip 47:** Show all problematic fields at once with clear indicators.

---

## Links

- [ ] **Tip 48:** Links must stand out — use blue and/or underlining.
- [ ] **Tip 49:** Links should always look like links.
- [ ] **Tip 50:** Link text should indicate where it leads.
- [ ] **Tip 51:** Don't use blue or underlining for non-links.
- [ ] **Tip 52:** Full URLs referenced should be linked.
- [ ] **Tip 53:** Expected clickable elements (product images, reviews) should be clickable.
- [ ] **Tip 54:** Use a different color for visited links to reduce cognitive load.

---

## Buttons

- [ ] **Tip 55:** Buttons must look clickable and have enough space.
- [ ] **Tip 56:** Frequent actions should be large and easy to reach.
- [ ] **Tip 57:** Colors, borders, and labels signal clickability.
- [ ] **Tip 58:** In flat designs, use contrast and action-oriented labels.
- [ ] **Tip 59:** Provide visual feedback within ~0.1 s after interaction.
- [ ] **Tip 60:** Buttons that change/delete data on mobile should require deliberate action.

---

## Search

- [ ] **Tip 61:** Always have a search field unless your site is very small.
- [ ] **Tip 62:** On desktops, the search field should look like a text box.
- [ ] **Tip 63:** Make search easy to find — top right is expected.
- [ ] **Tip 64:** Users look for "a little box to type in."
- [ ] **Tip 65:** Search fields should be wide enough to see full queries.

---

## Carousels

- [ ] **Tip 66:** Avoid carousels — each new slide erases memory of the previous.
- [ ] **Tip 67:** Dots are hard to see on mobile; use peeking images instead.
- [ ] **Tip 68:** Use descriptive labels instead of arrows.
- [ ] **Tip 69:** Only ~1% of users click carousel slides.
- [ ] **Tip 70:** Auto-sliding carousels should switch to manual after interaction.

---

## Accordions

- [ ] **Tip 71:** Use accordions to compress content on mobile.
- [ ] **Tip 72:** Allow users to collapse expanded content.
- [ ] **Tip 73:** Pros: shorter pages are easier than jump links.
- [ ] **Tip 74:** Cons: increased interaction cost; out of sight means out of mind.

---

## Help & Hints

- [ ] **Tip 75:** The main purpose of each page should be obvious.
- [ ] **Tip 76:** Users are reluctant to use Help — place it in context.
- [ ] **Tip 77:** Display hints only when needed.
- [ ] **Tip 78:** Help and instructions should be short and visually distinct.
- [ ] **Tip 79:** Show only one hint at a time to reduce memory load.

---

## Icons

- [ ] **Tip 80:** Icons must visually describe their function.
- [ ] **Tip 81:** Use icons only when necessary — avoid decoration.

---

## Content

- [ ] **Tip 82:** Most important info should be most visually prominent.
- [ ] **Tip 83:** Put key information first — users scan the first few words most.
- [ ] **Tip 84:** Place high-priority content at the top.
- [ ] **Tip 85:** Use color & size contrast to separate primary vs supporting details.
- [ ] **Tip 86:** Mobile priorities include location, events, phone number, emergency info.
- [ ] **Tip 87:** Prioritize for mobile context-sensitive information.
- [ ] **Tip 88:** Simple, obvious terms beat industry jargon.

---

## Readability

- [ ] **Tip 89:** Most users scan first, read later — use visual variety.
- [ ] **Tip 90:** Readability is about desire to read, not just legibility.
- [ ] **Tip 91:** Increase line spacing for better readability.
- [ ] **Tip 92:** Choose fonts with good legibility and styles.
- [ ] **Tip 93:** On mobile, consider larger x-height for readability.
- [ ] **Tip 94:** Avoid small fonts, especially for long text.
- [ ] **Tip 95:** Ensure responsive headline text sizes on mobile.
- [ ] **Tip 96:** Scale fonts to screen size.
- [ ] **Tip 97:** Avoid "banner blindness" — users ignore anything that looks like ads.
- [ ] **Tip 98:** Make long blocks easier to read by one idea per paragraph.
- [ ] **Tip 99:** Italicized text is harder to read (especially for dyslexic users).
- [ ] **Tip 100:** **Do not use ALL CAPS in headlines/taglines.**

---

## Quick Reference by Category

### Critical for Best City Spots
- **Search (Tips 61-65):** Search is prominent on homepage ✓
- **Loading (Tips 15-20):** Skeleton loaders implemented ✓
- **Mobile (Tips 21-27):** Touch targets need review
- **Links (Tips 48-54):** Link styling needs review
- **Buttons (Tips 55-60):** Button feedback timing needs review
- **Readability (Tips 89-100):** Font sizing and spacing need review

### Areas to Review
1. **Color & Contrast:** Ensure blue is only used for links, check colorblind accessibility
2. **Mobile Touch Targets:** Verify all interactive elements meet 1cm × 1cm minimum
3. **Navigation:** Consider breadcrumbs on city pages
4. **Content Hierarchy:** Verify most important info is most prominent
5. **Link Styling:** Ensure links are clearly distinguishable

## Notes

- This checklist should be reviewed regularly during development
- Mark items as complete when implemented and tested
- Prioritize items based on user feedback and analytics
- Consider A/B testing for major UX changes
