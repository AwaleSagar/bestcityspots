# Best City Spots — Atlas // Index 01

A premium, high-fidelity urban intelligence platform designed with a **Liquid Glass** aesthetic. Explore the world's most vibrant cities with real-time data and AI-driven insights.

## 💎 Design Philosophy

- **Liquid Glass UI:** Deep blacks, high-saturation blurs, and refraction effects powered by Tailwind CSS 4 and Vanilla CSS custom properties.
- **Atmospheric Motion:** Fluid background orbs, constellation particle effects, and smooth `framer-motion` transitions.
- **Architectural Typography:** Bold hierarchy using massive font weights and technical accents.
- **Dark / Light Theme:** Seamless theme switching via `next-themes`.
- **Adaptive UX:** Network-quality-aware image loading, responsive device detection, and virtual keyboard handling.

## 🧠 Intelligence & Data

- **AI-Powered Discovery:** Real-time travel trends and city briefings generated by **Google Gemini** (`gemini-3-flash-preview`), validated at runtime with Zod schemas.
- **Global Landmarks:** Top experiences, dining, and luxury stays ranked by a **Bayesian ranking engine** using data from the **Google Places API (New)**, with BlurHash image placeholders.
- **Real-time Weather & Air Quality:** Live meteorological conditions via **OpenWeatherMap** and air-quality (PM2.5) data from **Open-Meteo** (60-minute cache).
- **City Metrics:** Cost-of-living index, safety score, connectivity, pollution level, and health-access ratings.
- **Multi-Mode Search:** Full-text search (FTS), fuzzy matching, city aliases, geolocation (nearest city via GPS), and localStorage-persisted recent searches.
- **Intelligent Caching:** Layered TTLs in **Supabase** — 365-day AI insights, 30-day places (7-day soft refresh), 24-hour trending, and 60-minute weather — to minimize API costs and maximize speed.

## 📊 Analytics

- **Privacy-first visitor analytics** stored as aggregate daily tables in Supabase — no per-user profiles.
- **Metrics tracked:** daily visitor stats, traffic sources (organic / social / referral / direct / paid / email), device & browser breakdown, geographic distribution (with GDPR-compliant geo-consent banner), city view counts, and user actions (search, view city, click maps link).
- See `src/components/analytics/` and `src/app/api/analytics/`.

## 🛡️ Security & Validation

- **Input Validation:** Strict schema validation using **Zod** for all API inputs, AI responses, and environment variables.
- **Database Security:** Robust **Supabase RLS (Row Level Security)** policies on all tables (read-only for public data).
- **Security Linting:** Integrated `eslint-plugin-security` for object-injection, non-literal fs, and eval checks.
- **Hardened Headers:** HSTS (2-year max-age, includeSubDomains, preload), X-Frame-Options (SAMEORIGIN), X-Content-Type-Options (nosniff), Referrer-Policy (origin-when-cross-origin), and X-DNS-Prefetch-Control in `next.config.ts`.

## 🛠 Setup & Development

### Prerequisites

- **Node.js** 20.x or higher
- **npm** 10.x or higher

### Environment

Create a `.env.local` in the project root:

```env
# Required for core features
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key
GOOGLE_PLACES_API_KEY=your_google_places_key
GOOGLE_GEMINI_API_KEY=your_gemini_key

# Optional — weather (OpenWeatherMap)
OPENWEATHERMAP_API_KEY=your_openweathermap_key

# Optional — server-side Supabase (cache writes, admin)
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key

# Optional — SEO & verification
NEXT_PUBLIC_SITE_URL=https://bestcityspots.com
NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION=your_verification_token

# Optional — enable analytics in development
NEXT_PUBLIC_ANALYTICS_DEV=1
```

> **Note:** Placeholder values (e.g. `https://placeholder.supabase.co`) are sufficient for lint, type-check, and build. The app gracefully degrades data-fetching features when the backend is unreachable.

### Database

Apply the SQL scripts in `supabase/` to your Supabase project in order. Key tables:

| Table                   | Purpose                                                                         |
| ----------------------- | ------------------------------------------------------------------------------- |
| `cities`                | Core city data (name, coordinates, country, population)                         |
| `city_ai_insights`      | Cached Gemini briefings (365-day TTL)                                           |
| `city_places_cache`     | Google Places landmarks / restaurants / hotels (30-day TTL, 7-day soft refresh) |
| `city_weather_cache`    | Weather & AQI snapshots (60-minute TTL)                                         |
| `ai_trending_cache`     | AI-generated trending destinations (24-hour TTL)                                |
| `city_metrics`          | Aggregate metrics (cost, safety, connectivity, pollution, health)               |
| `daily_visitor_stats`   | Core visitor counts by date                                                     |
| `traffic_sources_daily` | Traffic breakdown (organic, social, referral, direct, paid, email)              |
| `device_stats_daily`    | Device / browser / OS breakdown                                                 |
| `geo_stats_daily`       | Geographic distribution (country, city)                                         |
| `city_views_daily`      | Most-viewed cities                                                              |
| `user_actions_daily`    | User actions (search, click, view)                                              |

```bash
npm run format                 # Prettier format

npm run warm-cache             # Warm intelligence / trending / places caches

npm run warm-cache:dry-run     # Dry run (no writes)
npm run analytics              # Analytics report (default 7-day window)
npm run analytics:30d          # Last 30 days
npm run analytics:json         # JSON output

```

### Docker

Build and run with Docker:

```bash
docker build -t bestcityspots \
  --build-arg NEXT_PUBLIC_SUPABASE_URL=... \
  --build-arg NEXT_PUBLIC_SUPABASE_ANON_KEY=... \
  --build-arg GOOGLE_PLACES_API_KEY=... \
  --build-arg GOOGLE_GEMINI_API_KEY=... \
  .

docker run -p 3000:3000 --env-file .env.local bestcityspots
```

Build args inject Next.js public env at build time. Runtime-only env vars (e.g. `OPENWEATHERMAP_API_KEY`, `SUPABASE_SERVICE_ROLE_KEY`) are passed via `--env-file` or `-e`.

Or use Docker Compose:

```bash
docker compose up --build
```
